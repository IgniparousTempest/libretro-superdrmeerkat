# Super Dr Meerkat artwork

For EmulationStation, use the [3D box](box-3d.png) or [box front](box-front.png) as the game image and the [transparent logo](logo.png) as the marquee. The [portrait cover](cover.png) is 2400 × 3600. [Gameplay and title screenshots](../.readme/) are also available.

The [back](box-back.png), [spine](box-spine.png) and front fit together in the [full box texture](box-texture.png). The [creator credit](credit-courtney-pitcher.png) has a transparent background. The [meerkat icon](meerkat-icon.svg) uses `currentColor` for themes.

The [vector originals](../assets/source/artwork/) use the game’s sprites and lettering. To regenerate the images, run `python3 tools/render_artwork.py` from the repository root with `rsvg-convert` and Pillow installed. [License](../LICENSE)
